The 2024 Nairobi floods, replayed on real rainfall

In April and May 2024, El Niño-driven rains flooded Nairobi's informal settlements. This page replays that window for Mathare and Mukuru using real recorded daily rainfall, then applies Kinga Maji's own deterministic rule — ≥ 20 mm of rain over standing water escalates the warning — day by day, so you can see which days the system would have flagged.

Retrospective replay using real daily rainfall from the Open-Meteo Historical Weather API (archive-api.open-meteo.com), 2024-04-01 to 2024-05-15, for Mathare (−1.2595, 36.8580) and Mukuru (−1.3167, 36.8667). Depth is illustrative here — Kinga Maji computes a real depth only from a photo with a known-height reference object, so no measured flood depths are invented on this page.
