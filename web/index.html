How it works

A number you can check, not a guess

The model only reads pixels. Every metre is computed by a deterministic engine and traced, so you can follow the arithmetic yourself.

1. Snap a photo

Take a flood photo next to a known object — a doorframe, a jerrycan, a matatu wheel.

2. Pixels only

The model measures the object and the waterline in pixels. It never invents a depth.

3. Deterministic metres

The engine turns the known height into a flood depth in metres — the same photo always gives the same number.

4. Rainfall + warning

Depth is fused with real per-location Open-Meteo rainfall, pulled at each settlement's own coordinates — Mathare (−1.26, 36.86) and Mukuru (−1.32, 36.87) — then a deterministic escalation rule raises the risk one notch when the forecast is heavy over standing water.

Every number is computed and traced, never guessed. The result card shows the full arithmetic, step by step. Rainfall is real Open-Meteo data fetched per settlement, feeding a deterministic escalation rule.

One real measurement, start to finish. The model only located the pixels; the diagram and the trace below are the exact deterministic steps that turn them into metres. Follow it, or recompute it by hand.

The method

A diagram of how a depth is computed from one reference object — not a photo. The arithmetic is the same for any uploaded image.

The deterministic trace
  1. Reference object = doorframe, documented height H = 2.030 m
  2. Reference pixel span = bottom(600) - top(100) = 500 px
  3. Scale = 500 px / 2.030 m = 246.3 px per metre
  4. Submerged span = bottom(600) - waterline(365) = 235 px
  5. Depth = 235 px / 246.3 px/m = 0.95 m (47.0% of the reference submerged)
  6. Depth 0.95 m falls in [0.90, 99.00) m -> category 'evacuate' (Evacuate)
  7. Forecast rainfall next 24h = 0.0 mm (Open-Meteo)
  8. Rule: no escalation (threshold not met)
